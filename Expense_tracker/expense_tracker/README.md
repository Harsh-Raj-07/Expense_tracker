# Expense Tracker (Python)

A simple terminal app to track your spending. No libraries to install.

## How to run
1. Install Python 3 (https://python.org) if you don't have it.
2. Unzip this folder.
3. Open a terminal inside the folder and run:

   python main.py        (Windows)
   python3 main.py       (Mac / Linux)

## Features
- Add expenses with category and date
- View all expenses with total
- Summary by category
- Delete an expense
- Data saved automatically in expenses.json
